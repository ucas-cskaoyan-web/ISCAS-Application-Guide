## 研究所概况

中国科学院软件研究所（ISCAS）成立于 1985 年 3 月 1 日，是一所致力于计算机科学理论和软件高新技术研究与发展的综合性研究所。所址位于北京市海淀区中关村南四街 4 号中国科学院软件园区。

官网：[中国科学院软件研究所](https://is.cas.cn/) · 招生信息：[研究生招生信息](https://is.cas.cn/yjsjy/zsxx/)

覆盖计算机、软件工程、AI 大模型、系统软件、数据库、分布式云计算、网络安全等领域。

<!-- kicker: WHY ISCAS -->
## 为什么选择软件所 {#value}

:::features
| title | description |
| --- | --- |
| 方向丰富 | 可信计算、并行软件、基础软件、人机交互等，国科大计算机学科评估 A+。 |
| 分数亲民 | 26 年学硕线 269，仅比国家线高 5 分；同级 985 计算机普遍 340–380+。 |
| 平台与地段 | 中科院体系、国家级重点实验室；地处中关村，实习就业资源集中。 |
| 免学费 + 高补助 | 研一补助 3.3 万+ / 年（北京），已含学费返还，读研基本自给自足。 |
| 不歧视双非与二战 | 更看重初试与复试表现，大量双非上岸案例可查。 |
| 保护一志愿 | 专硕可转学硕；不接受所外调剂，一志愿权益有保障。 |
:::

> 理性看待：分数亲民意味着进复试门槛低，但复试同样有筛选。初试分越高，主动权越大。
